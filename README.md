# 띵지고

명지대 셔틀버스를 놓친 학생을 위한 택시팟 모집 스트림릿 앱입니다.

## 실행

```powershell
cd C:\Users\hkkit\Documents\Codex\2026-07-28\thvm\outputs
python -m pip install -r requirements.txt
streamlit run app.py
```

`ddingjigo.db` 파일이 자동으로 생기며 게시글, 참여 상태, 댓글을 보관합니다. 운영 환경에서는 이 파일을 지속되는 볼륨에 두어야 합니다.

## 반영한 규칙

- 서비스명: **띵지고**
- 작성자는 자동으로 첫 참여자가 되며, 모집 정원은 1~4명입니다.
- 목록의 **참여하기**를 누르면 즉시 참여 처리 후 참여자/댓글 화면으로 이동합니다.
- 모든 참여자는 본인의 도착 상태를 바꿀 수 있고, 작성자를 제외한 참여자는 본인의 송금 완료 상태를 바꿀 수 있습니다.
- 닉네임은 숫자 8자리 학번을 권장합니다. 학번 형식이 아닌 참여자는 작성자에게 `학번 미확인 추방` 버튼이 표시됩니다.
- 작성자를 제외한 참여자 전원이 송금 완료를 누르면 게시글은 3시간 뒤 자동 삭제됩니다. 새 참여자가 생기면 삭제 예약은 취소됩니다.
- 학번을 저장하면 현재 브라우저 세션에서는 7일간 변경할 수 없습니다.
